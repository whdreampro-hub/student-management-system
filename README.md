# Student Management System

A complete school management system for administrators to manage student records, track academic history, promotions, and transfers.

## Features

- ✅ Admin Authentication (Single User)
- ✅ Complete Student CRUD Operations
- ✅ Student Photo Upload
- ✅ Academic Year Management
- ✅ Class Management
- ✅ Student Promotion System (Preserves History)
- ✅ Student Transfer System (Preserves History)
- ✅ Academic Timeline Tracking
- ✅ Student Search & Filter
- ✅ Reports Generation (PDF & Excel)
- ✅ Dashboard with Charts & Statistics
- ✅ Responsive Design (Bootstrap 5)
- ✅ AJAX Search
- ✅ SweetAlert2 Notifications
- ✅ Activity Logging
